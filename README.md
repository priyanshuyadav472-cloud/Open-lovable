## ✨ Features

- 🌐 **AI Website Cloner**: Enter any live website URL to scrape design tokens, color schemes, typography, and section layouts into full React components.
- 💬 **Interactive AI Pair Programmer**: Chat with Gemini to iteratively refine layouts, build new components, add interactive features, or restyle themes.
- 🎯 **Visual Element Inspector**: Click any component inside the live preview to target that exact element in your next AI prompt.
- 📱 **Responsive Sandboxed Preview**: Instant live execution with Desktop, Tablet (768px), and Mobile (375px) viewports with zoom controls.
- 💻 **Integrated Multi-File Code Editor**: File tree explorer, syntax highlighting, line numbers, and live sync with the sandbox.
- 📦 **1-Click Standalone ZIP Export**: Download a clean, production-ready Vite + React + TypeScript + Tailwind CSS project ready for `npm run dev`.
